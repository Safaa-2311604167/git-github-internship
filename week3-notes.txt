Git File Recovery Practice

Objective:
To understand how Git can restore a deleted file from a previous commit.

Tasks Completed:

Step 1: Created a test file.

echo "This is a Git recovery practice file." > recovery-test.txt

Step 2: Checked the repository status.

git status

Step 3: Added and committed the file.

git add recovery-test.txt
git commit -m "Add recovery test file"

Step 4: Deleted the test file.

rm recovery-test.txt

Step 5: Checked the deletion status.

git status

Step 6: Restored the deleted file.

git restore recovery-test.txt

Step 7: Verified the recovered file.

ls
cat recovery-test.txt

Verified Output:
This is a Git recovery practice file.

Step 8: Checked the final repository status.

git status

Result:
The deleted file was successfully recovered using the Git restore command. The working tree was clean after recovery.
